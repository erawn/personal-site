title: 'HiLT: A Library for Generating Human-in-the-Loop Data Transformation GUIs'
excerpt: 'Domain-specific data transformation tasks are best addressed with custom interfaces tailored to the user and the task, but authoring these interfaces can be difficult. We present a Python Library called HiLT which enables interfaces authors to specify data transformation steps as discrete stages, and HiLT generates the corresponding interfaces. In a user study we found that users had greater success with HiLT over popular UI frameworks and the stage metaphor helped programmers write their programs in terms of the data transformations they wanted, rather than UI components.'
