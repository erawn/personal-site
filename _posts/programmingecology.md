title: 'Programming Ecology'
excerpt: 'Designing Programming Systems requires thinking abstractly about the possible user behaviors a system''s features make possible and impossible, but effective designs for real programmers require grounding in observations of particular users. Through four project case studies, we introduce a design framework that brings these two ways of thinking together, helping programming systems designers identify design questions from user observations, reason about the consequences of system interventions, and ask deeper questions when evaluating new systems with users.'
